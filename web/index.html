🛰️ Time Beacon

Browser firmware installer for Heltec Wireless Tracker boards. No dev tools, command line, or Python required.

Requires Google Chrome, Microsoft Edge, or another Web Serial-compatible browser on desktop.
Web Serial is not supported in this browser. Please use Chrome or Edge on desktop.
Quick Instructions:
  1. Connect your Heltec Tracker to your PC using a high-quality USB-C data cable.
  2. Select your board version from the dropdown above.
  3. Click Connect & Install and select the serial port from the browser prompt.
  4. If the device isn't recognized, hold the USER / PRG button while connecting the USB cable to enter the ROM bootloader.
